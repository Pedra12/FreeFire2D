# FreeFire 3D Prototype

Projeto independente de reconstrução 3D em Godot 4.3. O protótipo 2D original permanece na raiz do repositório.

## Primeira fase
- Personagem 3D com colisão.
- Câmera em terceira pessoa com rotação por arrasto.
- Movimento por botões virtuais.
- Cenário 3D procedural com casas, árvores e estradas.
- Disparo básico por raycast.
- Exportação Android ARM64.

## Abrir
Importe esta pasta no Godot 4.3 usando o arquivo `project.godot`.

## Estado
É uma primeira base técnica, ainda sem bots, inventário, mapa final ou multiplayer. Os modelos atuais são formas primitivas temporárias e serão substituídos por assets 3D adequados.
